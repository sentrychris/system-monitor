Features

Built for at-a-glance clarity.

Everything you need to know about a host, surfaced in a layout that prioritizes signal over chrome. No setup wizards. No login walls.

Live WebSocket streaming

Sub-second metric updates pushed from a single shared sampler. N dashboards do not equal N scans.

D3-powered visualizations

Glowing line charts for CPU, memory, network, and disk I/O. Rolling 30s windows with smooth Y-axis transitions.

Service probes

Configurable HTTP health checks with status, latency, and inline failure reasons. Online · Slow · Offline at a glance.

Top processes

Aggregated by name, sized by memory. Uses PSS where available so shared libraries are not double-counted.

Storage breakdown

Per-partition usage, mountpoint, and fstype. Disk read/write throughput and IOPS as a live dual-series chart.

Light & dark themes

Seamless theme toggle with persisted preference. Charts re-tune their grid and axis colors automatically.

How it works

A two-piece system.

Vigil is the polished frontend; Vigil Collector does the host-side work. They talk over HTTP and a WebSocket — that is it.

Backend

Vigil Collector

  • asyncio sampler · 1 Hz default
  • psutil + Tornado
  • HTTP /system, /network, /probes
  • WebSocket /connect
  • Linux & Windows
JSON · 1 Hz
Frontend

Vigil

  • Vue 3 · Pinia · TypeScript
  • D3 realtime charts
  • Bootstrap layout · Sass tokens
  • Dark + light theme
  • Static or live mode
Quick start

Up and running in under a minute.

Run Vigil Collector on the host you want to watch, then point Vigil at it. That is the whole setup.

Grab the prebuilt single-file Vigil Collector binary — no Python install required on the target host.

Download v1.0.0

~/vigil — bash 
# 1. Drop the binary on PATH and start the collector
$ chmod +x vigil-collector
$ mv vigil-collector ~/.local/bin/   # or: sudo mv ... /usr/local/bin/
$ vigil-collector --address=0.0.0.0 --port=4500

# 2. Clone Vigil and point it at Vigil Collector
$ git clone https://github.com/sentrychris/vigil
$ cd vigil && npm install
$ cp .env.example .env  # edit URLs

# 3. Build & serve
$ npm run build
$ npm run preview
  ➜  Local: http://localhost:4173
1

Install Vigil Collector on the host

Place the downloaded binary somewhere on your PATH — ~/.local/bin/ for a single user, /usr/local/bin/ system-wide. It runs the sampler and exposes HTTP + WebSocket endpoints. Repo →

2

Configure Vigil's environment

Set VITE_API_URL, VITE_WORKER_URL, and VITE_WEBSOCKET_URL to point at your Vigil Collector instance.

3

Build & deploy

Vite emits a static dist/ you can serve with anything — nginx, Caddy, GitHub Pages, an S3 bucket. No runtime needed.

4

Toggle live / static

The navbar switch flips between WebSocket (1 Hz live) and HTTP polling (30 s). Both speak the same payload shape.

Build Vigil Collector from source

Prefer to build it yourself? Clone the repo and install with pip, or roll your own one-file binary with PyInstaller.

~/vigil-collector — bash 
# Run from a checkout (requires Python 3.10+)
$ git clone https://github.com/sentrychris/vigil-collector
$ cd vigil-collector && pip install -e .
$ vigil-collector --address=0.0.0.0 --port=4500

# Or produce a standalone binary with PyInstaller
$ pip install -e ".[build]"
$ pyinstaller vigil-collector.spec
  ➜  Output: dist/vigil-collector
